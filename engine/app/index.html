Assemblage*

real time segmentation and rebuilding of arbitrary 3D models in a physics environment

  • KREA 2 to create a source images and TRELLIS 2 to convert images to 3D models.
  • the models are passed to an auto-segmentation algorithm to retrieve meaningful submeshes.
  • the submeshes are used to rebuild an arbitrary 3D object using a packing algorithm.
  • the app uses a SDF-based CPU/WebGPU physics engine.

drag the models, double click to create an explosion, then rebuild a target model with the parts present on stage (or clear and add random parts).

on mobile, long press the create and rebuild buttons to select the models.
