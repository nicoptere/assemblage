Drop impact samples here (any folder layout, ogg / wav / mp3 / flac / m4a / opus), then run
`npm run sounds` in engine/app. Words in the paths sort them: heavy / large / big / huge / deep / low,
light / small / tiny / little / high, medium / mid (or no hint); sheet / plate / foil / panel / tin / thin
for sheet metal. Each part plays from its shape (sheet or solid) and its mass class
(light < 0.12 kg <= medium < 0.75 kg <= heavy). While this folder is empty, impacts are synthesised.
